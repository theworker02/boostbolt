# boostbolt

Boost identifiers and bolt tokens for idempotent workflows.

**Site:** https://theworker02.github.io/boostbolt/

## Install / run

```bash
git clone https://github.com/theworker02/boostbolt.git
cd boostbolt
node src/cli.js
node --test
```
